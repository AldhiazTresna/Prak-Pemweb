# Tugas Pemrograman Web - Portofolio Proyek Interaktif

Aplikasi Portofolio Interaktif berbasis HTML, Tailwind CSS, dan JavaScript Vanilla (Native).

## Fitur Utama:
1. *Formulir Input Proyek Dinamis:* Tambah proyek baru dengan validasi judul dan anggaran, serta id unik (Date.now()).
2. *Pencarian Real-Time & Filter Terpadu:* Fitur pencarian live nama proyek menggunakan .filter() dan .toLowerCase().includes().
3. *Aksi Interaktif Kartu Proyek:* Mengubah status proyek ('Selesai' / 'Dalam Pengerjaan') dan menghapus proyek dari array secara instan serta mengupdate statistik.
